- (decision) Build UX from existing PRD (prd-game-2026-07-25) as source of truth for journeys/FRs/glossary; coaching-path working mode selected.
- (decision) Target emotional register: anticipation (not horror/dread) — player should feel a pull toward what's next, fitting the 'almost right but wrong' branch-reality hook.
- (decision) Bundled branch-reality illustrations (FR-12) render as full-screen interstitial moments, shown when the player arrives in a new branch reality — not small accents or persistent backgrounds.
- (decision) Reading experience is text-forward, Kindle/Apple-Books-like (large HIG text area, paged), but distinctly styled — not a generic reader chrome. User specifically wants a consistent border/frame element that visually ties screens together as a signature app motif.
- (decision) No fixed reference points given; user opted to see generated visual directions rather than name existing apps/works to emulate.
- (decision) Visual direction locked: 'Warm Ink, Circuit Frame' — Hybrid B's warm-ink-on-paper palette (surface #FAF6EE/#241C14, ember accent #C2540F, brass trace #8B6F47) with corner treatment redrawn as circuit-trace geometry (trace lines + via node + open pads) instead of a plain bracket/hairline. Frame stays dormant/brass on ordinary pages and powers up to ember with a glow exactly on choice-echo moments. Reference mock promoted to mockups/story-choice-warm-ink-circuit.html.
- (decision) Dark-mode variant requested (not single-theme) — added -dark suffix tokens: surface-base-dark #1C1712, surface-raised-dark #262019, ink-primary-dark #F3ECDD, accent-ember-dark #E0763A (brightened for legibility on dark ground), trace-brass-dark #C9A876, selected-fill-dark #3A2E1E. - (decision) Resolved PRD Open Question 2 (gesture vocabulary): choice selection is press-and-hold (~3s charge, brass fill on the card) to commit; a quick tap commits identically and instantly, serving as the always-available accessible/VoiceOver equivalent (not gesture-only, satisfies FR-11). Holding a different card cancels an in-progress charge. Choice count is usually 2, occasionally 3 (gotcha option) — hold-based commit scales to either without new gesture design, unlike the swipe-direction alternatives considered.
- (event) DESIGN.md updated: added charge-fill-color/charge-duration tokens to components.choice-button to back the hold-to-confirm interaction.

- (decision) Mid-run exit/restart resolved: subtle ellipsis-circle 'run options' icon (trace-brass) top-right of the reading card on Story/Choice + Tutorial pages, opening a native action sheet: Exit to Home (non-destructive, preserves progress) / Restart This Run (destructive, requires confirmation) / Cancel. Home's primary action relabels Start Story -> Resume Story when a run is in progress. Absent from interstitial and Home.

Ending is the one place the frame's ember/active state is permanent/resting rather than a transient echo signal -- represents run resolution.
